# Deep Learning for Natural Language Processing

This repository contains structured implementations and notes for Deep Learning applied to Natural Language Processing (NLP).
The progression follows the evolution from classical statistical methods to modern Transformer-based architectures.

Each notebook focuses on both theory + practical implementation (PyTorch-based).
